# Corporate Travel Product Glossary

| Term | Meaning |
|---|---|
| Traveller | Employee or authorised person undertaking business travel |
| Travel arranger | Person authorised to create or manage requests for another traveller |
| Approver | Person authorised to approve, reject or return a travel request |
| Policy rule | Configured condition governing eligibility, choice or approval |
| Policy exception | A request or selection that does not meet one or more configured policy rules |
| Trip request | Internal request to undertake travel; not a supplier booking |
| Booking | Reservation request or confirmed reservation with a travel supplier |
| PNR | Passenger Name Record used in supported flight booking workflows |
| Ticketing | Issuance of an airline ticket following the relevant reservation process |
| Supplier reference | Identifier returned by an airline, hotel or other travel provider |
| Reconciliation | Process of comparing platform records against provider or finance records |
| Cost centre | Finance / organisation reference used to allocate travel cost |
| Servicing | Post-booking activities such as changes, cancellation and refund tracking |
| Unused ticket | Airline ticket value that may be eligible for future use under applicable rules |

Terms and definitions may vary by supplier, organisation and market. Confirm the relevant business meaning before using them in requirements.

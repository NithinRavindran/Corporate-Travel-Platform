# User Stories

## Traveller

- As an employee, I want to create a trip request with required details so that my travel can be reviewed and arranged.
- As an employee, I want to understand why an option is outside policy so that I can choose an appropriate alternative or request an exception.
- As an employee, I want to see whether my request is pending, approved or booked so that I know what action is required.
- As a traveller, I want to view my confirmed itinerary so that I can prepare for the trip.

## Travel arranger

- As an authorised arranger, I want to create a request for an employee so that I can manage travel on their behalf.
- As an arranger, I want to see requests awaiting approval so that I can follow up on delayed decisions.
- As an arranger, I want to access booking references and supplier status so that I can support the traveller.

## Approver

- As an approver, I want to see itinerary, estimated cost, policy status and business purpose so that I can make an informed decision.
- As an approver, I want to request clarification so that incomplete requests are not approved without context.
- As an approver, I want decisions recorded so that the approval history is auditable.

## Administrator

- As a corporate administrator, I want to configure policy rules and approval hierarchy so that workflows reflect organisation requirements.
- As an administrator, I want to test policy changes before publishing so that rule changes do not produce unexpected outcomes.

## Travel operations

- As an operations agent, I want to view supplier responses and booking events so that I can investigate unresolved booking outcomes.
- As an operations agent, I want to record servicing actions so that the trip timeline remains traceable.

## Finance

- As a finance analyst, I want bookings associated with valid cost allocation so that travel spend can be reconciled.

# Release Readiness Checklist

## Product
- [ ] Scope, non-goals and known limitations documented.
- [ ] Domestic, international and multi-city user journeys approved.
- [ ] User journeys and acceptance criteria approved for web and mobile.
- [ ] Policy rules and approval matrix signed off by business owner.
- [ ] Spend forecast definitions and policy insight explanations reviewed by finance / travel policy owners.
- [ ] Release notes and user communication ready.

## Engineering and integrations
- [ ] Supplier contract and mapping tests passed.
- [ ] Time-zone, daylight-saving and date-boundary behaviour validated.
- [ ] Currency display and conversion metadata validated.
- [ ] Timeout, retry, idempotency and reconciliation behaviour validated.
- [ ] Mobile notification, session and secure cache behaviour tested.
- [ ] Forecast data lineage, refresh, coverage and quality checks configured.
- [ ] Monitoring, alerting and dashboards configured.
- [ ] Rollback and recovery approach documented.
- [ ] Data migration and backward compatibility reviewed.

## Security and privacy
- [ ] Role permissions tested across web and mobile.
- [ ] Secrets excluded from repository and logs.
- [ ] Personal data access, notification payloads, cache expiry and retention reviewed.
- [ ] Audit records validated.
- [ ] Mobile lost-device / session revocation process verified.

## Operations
- [ ] Support ownership and escalation route assigned.
- [ ] Exception queue and booking reconciliation process tested.
- [ ] Supplier contact and escalation process documented.
- [ ] Finance reconciliation process tested.
- [ ] Forecast owner, refresh cadence and policy insight review owner assigned.
